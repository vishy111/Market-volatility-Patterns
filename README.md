# Market-volatility-Patterns


The main message of this narrative visualization is that market volatility follows
identifiable patterns that become clearer when closing price, SD20 volatility, and Bollinger
Bands are viewed together over time. Using AAPL data from early 2020 during COVID-19
market shock, the story shows how stable periods shift into uncertainty and then sharp market
stress. The goal is to show that volatility is not random noise. It changes in ways that can be
observed directly through the chart data. By the time the viewer reaches the final scene, they
have seen how all the chart elements connect. The exploration mode then lets them test that
message on their own by zooming, toggling options, and changing time windows.
